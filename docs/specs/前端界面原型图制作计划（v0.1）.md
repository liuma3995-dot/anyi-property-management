## 一、背景与目标

模型基线已冻结，开发尚未启动。本计划先行制作**前端界面原型图**，目标是：

1. 将 DM-05 的线框级界面设计转化为可视化原型，供项目负责人直观评审；
2. 通过原型提前确认页面布局、交互路径与视觉风格，降低开发返工；
3. 原型页面与用例、库表建立映射，作为 WPF 前端开发的界面基准。

原型范围：WPF 桌面客户端（1366×768 主窗口），覆盖七大子系统 + 系统设置，共 36 个页面。

## 二、工具说明与决策记录

- 当前会话可调用工具列表中**是否暴露 pencil 的绘图工具**：以本次复核结果为准（见交付说明）；
- figma MCP 方案已取消，不再作为原型制作工具；
- 决策过程与备选：

| 选项 | 说明 | 影响 |
|---|---|---|
| A（已确认） | 恢复采用 pencil MCP 制作原型 | 产出 Pencil 源文件（.epgz）与导出图，页面清单与评审点不变 |

## 四、原型规范

| 项 | 规范 |
|---|---|
| 画布尺寸 | 主窗口页 1366×768；表单/弹窗页 1024×768（或按内容） |
| 视觉风格 | 扁平化 + 圆角控件；主色建议物业蓝（#2B7DE9），可评审调整 |
| 字体 | 微软雅黑，正文 12-14px，标题 16-20px |
| 通用范式 | 左导航 + 顶部用户区 + 内容区；列表-详情；筛选/搜索置顶 |
| 交互标注 | 关键操作（收款、应急发起、结案）标注跳转路径与确认提示 |
| 组件对齐 | 原型组件尽量对齐 HandyControl 控件（Button/DataGrid/ComboBox/MessageBox 等），便于前端直接参考 |
| 输出 | Pencil 源文件（.epgz）＋ 每页 PNG ＋ 总览 PDF（导出） |
