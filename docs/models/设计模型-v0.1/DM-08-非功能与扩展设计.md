# DM-8 非功能与扩展设计

> 制品：DM-08 ｜ 版本：v0.2（前后端分离部署）｜ 状态：待评审
> 输入：计划文档 2.5 非功能需求、P-01~P-09 确认参数

## 一、性能

| 场景 | 目标 |
|---|---|
| 常规操作（查询/保存） | ≤ 1 秒（单用户） |
| 批量生成账单（千户级） | ≤ 10 秒 |
| 财务报表生成 | ≤ 5 秒 |
| 电话簿/设备/纠纷检索 | ≤ 1 秒（含模糊搜索） |

## 二、可用性与恢复

| 项 | 目标 |
|---|---|
| 部署形态 | 单机，前后端双进程（WPF 客户端 + 本地后端服务），无网络依赖 |
| RPO（数据丢失容忍） | ≤ 24 小时（每日自动备份） |
| RTO（恢复时间） | 小时级（恢复最近备份文件） |
| 备份 | 每日自动 + 手动，保留 30 份，建议异机拷贝 |
| 升级 | 客户端/服务端分别升级，升级前自动备份，失败可回退 |

## 三、数据完整性

- 关键写操作事务化：收款 = 账单状态更新 + 缴费记录 + 收据 + 审计，同一事务；
- 外键约束 + 唯一约束：房号唯一（BR-INF-01）、同周期账单唯一（BR-FIN-01）、收据号唯一（BR-FIN-08）；
- 软删除 + 只追加审计，防止数据丢失与篡改；
- 状态流转由领域层校验（账单/应急/纠纷/设备），非法状态转换阻止。

## 六、部署与运维

1. 安装包一次部署"WPF 客户端 + 本地后端服务 + .NET Framework 4.8 运行时"（Inno Setup）；
2. 后端服务注册为开机自启（Windows 服务或启动项），默认端口 5210 可配置；
3. 数据文件、导出文件、备份文件统一由后端管理（用户数据目录），前端经 API 上传/下载；
4. 提供"备份/恢复"界面与"升级前自动备份"机制，客户端与后端分别升级；
5. 启动自检：后端校验端口占用与数据库完整性，客户端校验后端可达并提示；
6. 日志分级：审计日志（业务，后端）、运行日志（排障），运行日志可配置保留周期。

## 七、前后端分离带来的约束

- 前端任何数据变更都经 HTTP API，禁止直连数据库；
- 网络异常（后端未启动）时前端提示"服务未启动"，并提供一键启动入口；
- 本地回环调用开销极小（毫秒级），不影响单机性能目标；
- 契约（DTO）变更需前后端同步发布，Contract 项目统一管理。
