# DM-7 权限与安全设计

> 制品：DM-07 ｜ 版本：v0.2（前后端分离安全）｜ 状态：待评审
> 输入：AM-01（唯一系统管理员）、AM-06（BR-COM-xx）、P-02 确认参数

## 一、角色与会话

- 系统仅设**系统管理员**一个登录角色（评审确认），登录账号与员工档案解耦；
- 登录成功后由后端签发 token（随机、有效期可配），前端请求头携带 `Authorization: Bearer {token}`；
- 密码哈希存储（BCrypt，加盐），前端不保存密码明文；
- 连续失败 5 次锁定 30 分钟（P-02，参数可配），支持管理员重置。

## 一·五、API 安全

| 项 | 设计 |
|---|---|
| 绑定 | 后端仅绑定 `127.0.0.1:5210`，不暴露局域网 |
| 认证 | 每次请求校验 Bearer token；token 无效/过期返回 401 |
| 传输 | 本机回环通信；将来开放局域网时再启用 HTTPS |
| 数据隔离 | 前后端仅传输 DTO（JSON），不暴露实体与数据库结构 |
| 敏感操作 | 审计日志由后端写入，前端不可修改 |
| 启动校验 | 后端启动时校验端口占用与数据库完整性 |

## 二、权限矩阵

管理员拥有七大模块 + 公共的全部操作权限（查看/新增/修改/删除/导出/打印）：

| 模块 | 查看 | 新增 | 修改 | 删除 | 导出 | 打印 |
|---|---|---|---|---|---|---|
| 基础信息 | ✓ | ✓ | ✓ | 软删 | ✓ | — |
| 财务收费 | ✓ | ✓ | ✓ | 软删 | ✓ | ✓（收据/报表） |
| 应急处置 | ✓ | ✓ | ✓ | 软删 | ✓ | — |
| 人员组织 | ✓ | ✓ | ✓ | 软删 | ✓ | — |
| 便民电话簿 | ✓ | ✓ | ✓ | 软删 | ✓ | — |
| 纠纷调解 | ✓ | ✓ | ✓ | 软删 | ✓ | — |
| 设备台账 | ✓ | ✓ | ✓ | 软删 | ✓ | — |
| 系统设置 | ✓ | ✓ | ✓ | — | ✓ | — |

> 删除统一为软删除（del_flag），不做物理删除；紧急号码禁止删除（BR-TEL-03）。

## 三、敏感操作审计清单

| 操作 | 审计内容 | 触发点 |
|---|---|---|
| 收款 | 账单、金额、方式、收据号 | BR-COM-01 |
| 退款/减免/调整 | 类型、金额、原因、原账单 | BR-FIN-06 |
| 支出登记/修改 | 分类、金额、关联对象 | BR-FIN-10 |
| 删除（软删除） | 对象、操作人、时间 | BR-COM-06 |
| 结案（应急/纠纷） | 案件、结案类型、时间 | BR-EMG-06 / BR-DIS |
| 设备报废/状态变更 | 设备、新旧状态、原因 | BR-EQP-01 |
| 基础数据导入 | 批次、成功/失败数、错误清单 | BR-INF-05 |
| 备份/恢复 | 文件、时间 | BR-COM-04 |
| 字典/参数修改 | 字典项、参数、新旧值 | BR-COM-05 |

审计日志只追加（不可修改删除），供查询审计日志用例（UC-COM-003）检索。

## 四、数据安全

| 项 | 设计 |
|---|---|
| 密码 | 加盐哈希存储，最小 8 位，支持强制改密 |
| 软删除 | 核心业务表统一 del_flag，查询默认过滤 |
| 审计 | 敏感操作写入 t_audit_log，只追加 |
| 备份 | 每日自动备份 + 手动备份，保留最近 30 份（P-09），支持恢复到备份点 |
| 数据文件 | 单机数据库文件本地存储，建议系统账号与目录权限限制访问 |

## 五、单机部署安全建议

1. 运行系统使用 Windows 标准用户账号，不长期使用管理员权限运行；
2. 定期将备份导出到外部介质（U 盘/移动硬盘），防硬盘故障丢失；
3. 安装防病毒软件并定期更新；数据库文件与导出文件存放于用户数据目录；
4. 升级前自动备份数据文件，升级失败可回退；
5. 系统参数（锁定阈值、备份保留份数）通过 t_param 配置，界面可调整。

## 六、与 AM-01/AM-06 的追溯

- 唯一管理员角色：与 AM-01 一致；
- 登录锁定、停用控制：BR-COM-02/03；
- 敏感操作审计：BR-COM-01、BR-FIN-06/10、BR-EMG-06、BR-INF-05；
- 备份恢复：BR-COM-04；字典扩展：BR-COM-05。
