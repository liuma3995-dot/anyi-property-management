# DM-5 界面设计

> 制品：DM-05 ｜ 版本：v0.2（WPF 前端确认）｜ 状态：待评审
> 输入：AM-02 用例（60 个）、DM-01 架构
> 说明：WPF 客户端界面（HandyControl 主题），布局与关键页面原型（线框级），覆盖七大模块全部主要功能；页面数据一律经本地后端 API 获取，前端不直接访问数据库。

## 一、主窗口布局

```
+------------------------------------------------------------------+
| 物业管理系统                                    [管理员] [退出]      |
+--------+---------------------------------------------------------+
| 仪表盘  |                                                         |
| 基础信息|                                                         |
| 财务收费|                   内容区                                 |
| 应急处置|            （列表-详情 / 表单 / 查询 / 报表）              |
| 人员组织|                                                         |
| 电话簿  |                                                         |
| 纠纷调解|                                                         |
| 设备台账|                                                         |
| 系统设置|                                                         |
+--------+---------------------------------------------------------+
| 状态栏：当前用户 / 待办提醒（欠费、应急、纠纷、保养年检、复盘）        |
+------------------------------------------------------------------+
```

- 左侧导航固定展示七大模块 + 系统设置；点击切换内容区；
- 顶部为当前用户与退出；状态栏常驻提醒入口（点击跳转对应模块）；
- 内容区通用"列表-详情"范式：上方筛选/搜索，中间列表，下方或右侧详情/操作区。

## 三、模块主页面一览

| 模块 | 主页面 | 关键操作 |
|---|---|---|
| 基础信息 | 房产列表（按楼栋/业主/状态筛选） | 新增房产/业主/车位、关系维护、Excel 导入、导出 |
| 财务收费 | 账单/收款工作台 | 生成账单（草稿→发布）、收款登记、退款调整、欠费台账、收支流水、报表 |
| 应急处置 | 应急场景列表 + 事件工作台 | 场景/步骤维护、一键发起、指派、处置记录、结案、复盘 |
| 人员组织 | 员工列表 + 排班/考勤页 | 部门/岗位/员工维护、排班发布、考勤审核、在岗状态 |
| 电话簿 | 电话查询页 | 分类/条目维护、搜索、一键复制拨打、员工通讯录同步 |
| 纠纷调解 | 纠纷列表（状态筛选） | 登记、处理记录、进度更新、结案（类型化）、统计 |
| 设备台账 | 设备列表 + 到期提醒页 | 设备档案、保养/年检登记、故障登记、维保单位维护 |
| 系统设置 | 参数/字典/备份页 | 字典维护、备份/恢复、审计日志查询、改密 |

## 五、交互总原则

1. 列表-详情为通用范式，查询优先（电话簿、设备、纠纷、账单、员工均适用）；
2. 高频操作路径 ≤ 3 步：收款（业主→账单→收款）、应急（场景→信息→保存）、电话查询（一键打开）；
3. 应急页面提供"一键拨打"（联动电话簿）与"一键发起"；
4. 关键操作（收款、退款、结案、报废、导入、恢复）二次确认，敏感操作提示审计留痕；
5. 所有列表支持筛选、分页、导出（Excel）。
