## 二、阅读顺序

1. DM-01 架构（总览）→ DM-02 组件（边界）→ DM-03 类（职责）→ DM-04 库表（落地）；
2. DM-05 界面、DM-06 时序面向使用体验；DM-07 安全、DM-08 扩展面向质量与演进。

## 三、评审要点

- 前后端分离与单机部署是否匹配实际使用（WPF 客户端 + 本地 API 服务）；
- 组件边界与七大子系统是否一致、有无循环依赖；
- 库表是否支撑分析模型全部用例与规则（欠费口径、状态流转、到期提醒）；
- 界面是否覆盖全部主要功能，操作路径是否足够短；
- 决策点清单是否确认（技术选型 D-1~D-3、预存款 P-06 等）。
