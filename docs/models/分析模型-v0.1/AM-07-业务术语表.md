# AM-7 业务术语表

> 制品：AM-07 ｜ 版本：v0.4（按评审结论调整：移除角色/权限术语）｜ 状态：待评审
> 目标：全系统术语统一，避免各模块各自定义。

> 调整说明（v0.2）：系统仅设系统管理员唯一角色，已移除"角色""权限"两个术语；账号（登录）与业务员工档案解耦。

| 术语 | 定义 | 别名 | 所属模块 |
|---|---|---|---|
| 业主 | 房产权利人，可自住或出租 | 产权人、户主 | 基础信息 |
| 租户 | 非业主的住户（扩展预留） | 承租人 | 基础信息 |
| 房产 | 最小管理单元（房间） | 房屋、房间、户 | 基础信息 |
| 车位 | 停车位，分固定/临时 | 停车位 | 基础信息 |
| 台账 | 记录的登记簿 | 档案 | 通用 |
| 收费项目 | 收入类型（物业费/停车费/商铺管理费/杂项收入） | 收费类型 | 财务 |
| 计费周期 | 账单生成的时间段（月/季/年） | 周期 | 财务 |
| 应收账单 | 对缴费对象生成的应收款记录 | 账单 | 财务 |
| 缴费记录 | 一次收款流水 | 收款记录 | 财务 |
| 部分缴 | 缴费金额小于账单金额的状态 | 部分缴费 | 财务 |
| 欠费 | 到期未缴的金额 | 欠款 | 财务 |
| 逾期 | 超过到期日仍有欠款 | 超期 | 财务 |
| 冲正 | 退款/减免/调整对账单的修正 | 红冲、调整 | 财务 |
| 支出分类 | 支出类型字典（工资/维护/水电/外包/杂项） | 费用类别 | 财务 |
| 收据 | 收款凭证，编号唯一 | 凭据 | 财务 |
| 流水 | 收支明细记录 | 明细 | 财务 |
| 结余 | 收入减支出的余额 | 余额 | 财务 |
| 应急场景 | 六类突发情况类型 | 场景 | 应急 |
| 处置步骤 | 场景下的操作清单 | 操作步骤、指引 | 应急 |
| 应急事件 | 一次实际应急过程 | 事件 | 应急 |
| 复盘 | 事后原因分析与改进记录 | 复盘记录 | 应急 |
| 值班人 | 按排班当值的人员 | 当班人 | 人员/应急 |
| 责任人 | 事件/设备指定的负责人 | 负责人 | 人员/应急/设备 |
| 排班 | 员工 × 班次 × 日期的安排 | 值班表 | 人员 |
| 班次 | 排班的基本时段 | 班 | 人员 |
| 考勤 | 签到/签退及对照记录 | 打卡 | 人员 |
| 在岗状态 | 员工当前是否在岗 | 状态 | 人员 |
| 岗位 | 部门内职责单元 | 职位 | 人员 |
| 审计日志 | 敏感操作的留痕记录 | 操作日志 | 公共 |
| 电话条目 | 一条电话记录 | 号码 | 电话簿 |
| 置顶 | 常用/紧急号码优先展示 | 常用 | 电话簿 |
| 纠纷案件 | 一次纠纷的登记到结案全过程 | 案件 | 纠纷 |
| 调解员 | 负责纠纷处理的人员 | 处理人 | 纠纷 |
| 结案 | 纠纷解决并归档 | 完结 | 纠纷 |
| 归档 | 完结记录转入存档状态 | 存档 | 通用 |
| 设备台账 | 设备档案登记簿 | 设备档案 | 设备 |
| 保养 | 按周期对设备的维护 | 维护 | 设备 |
| 年检 | 年度检验 | 检验 | 设备 |
| 故障记录 | 设备故障的历史记录 | 故障历史 | 设备 |
| 维保单位 | 外部维护服务单位 | 维保商 | 设备 |
| 软删除 | 标记删除但保留数据 | 逻辑删除 | 公共 |
| 仪表盘 | 首页关键指标视图 | 首页 | 公共 |
