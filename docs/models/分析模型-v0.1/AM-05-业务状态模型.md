# AM-5 业务状态模型

> 制品：AM-05 ｜ 版本：v0.4（角色简化同步）｜ 状态：待评审

## 一、应收账单状态

```mermaid
stateDiagram-v2
  [*] --> 待缴
  待缴 --> 部分缴 : 部分缴费
  待缴 --> 已缴 : 全额缴费
  待缴 --> 逾期 : 超过到期日未缴
  部分缴 --> 已缴 : 缴清剩余
  部分缴 --> 逾期 : 超过到期日
  逾期 --> 已缴 : 缴清
  已缴 --> 已冲正 : 退款/减免/调整
  部分缴 --> 已冲正 : 退款/减免/调整
  已冲正 --> [*]
```

| 状态 | 进入条件 | 说明 |
|---|---|---|
| 待缴 | 账单生成发布 | 应缴未缴 |
| 部分缴 | 收款金额 < 账单金额 | 剩余计入欠费 |
| 逾期 | 超过到期日仍有欠款 | 进入欠费台账 |
| 已缴 | 收款金额 = 账单金额 | 正常完结 |
| 已冲正 | 退款/减免/调整 | 保留原记录，审计可查 |

## 二、应急事件状态

```mermaid
stateDiagram-v2
  [*] --> 已发起
  已发起 --> 处置中 : 开始处置
  处置中 --> 已结案 : 处置完成结案
  已结案 --> 已复盘 : 复盘完成
  已复盘 --> [*]
```

| 状态 | 进入条件 | 说明 |
|---|---|---|
| 已发起 | 场景选择并录入信息 | 自动带出步骤、匹配人员 |
| 处置中 | 责任人开始处置 | 记录过程 |
| 已结案 | 处置完成 | 归档，可补录复盘/处置记录 |
| 已复盘 | 复盘记录完成 | 终态 |

## 三、纠纷案件状态

```mermaid
stateDiagram-v2
  [*] --> 已登记
  已登记 --> 处理中 : 指派调解员/记录方案
  处理中 --> 已结案 : 结案归档
  已结案 --> [*]
```

| 状态 | 进入条件 | 说明 |
|---|---|---|
| 已登记 | 纠纷信息录入 | 未开始处理 |
| 处理中 | 指派调解员并记录方案 | 可多次补充处理记录 |
| 已结案 | 问题解决并归档 | 终态，可补录记录 |

## 四、设备状态

```mermaid
stateDiagram-v2
  [*] --> 在用
  在用 --> 维修中 : 故障/保养年检不合格
  在用 --> 停用 : 停用
  维修中 --> 在用 : 维修完成
  停用 --> 在用 : 重新启用
  停用 --> 报废 : 报废
  维修中 --> 报废 : 报废
  报废 --> [*]
```

| 状态 | 进入条件 | 说明 |
|---|---|---|
| 在用 | 设备启用 | 正常状态 |
| 维修中 | 故障或检验不合格 | 可关联故障记录 |
| 停用 | 人为停用 | 保留档案 |
| 报废 | 报废审批 | 终态，档案保留 |

## 五、员工状态

```mermaid
stateDiagram-v2
  [*] --> 在职
  在职 --> 离岗 : 离岗/休假
  在职 --> 离职 : 离职
  离岗 --> 在职 : 返岗
  离职 --> [*]
```

| 状态 | 进入条件 | 说明 |
|---|---|---|
| 在职 | 入职 | 可排班、可应急匹配 |
| 离岗 | 离岗/休假 | 应急匹配排除 |
| 离职 | 离职办理 | 账号停用、档案保留 |

## 六、考勤记录状态

```mermaid
stateDiagram-v2
  [*] --> 已记录
  已记录 --> 正常 : 与排班一致
  已记录 --> 异常 : 与排班不一致
  异常 --> 已审核 : 管理员审核
  已审核 --> [*]
  正常 --> [*]
```

| 状态 | 进入条件 | 说明 |
|---|---|---|
| 已记录 | 签到/签退 | 待对照 |
| 正常 | 与排班一致 | 自动判定 |
| 异常 | 缺卡/迟到/早退等 | 需审核 |
| 已审核 | 管理员审核通过 | 终态，可修正 |

## 七、补充：电话条目状态

```mermaid
stateDiagram-v2
  [*] --> 启用
  启用 --> 停用 : 停用（保留历史）
  停用 --> 启用 : 重新启用
```
