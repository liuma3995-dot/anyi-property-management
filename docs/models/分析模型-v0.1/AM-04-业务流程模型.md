# AM-4 业务流程模型

> 制品：AM-04 ｜ 版本：v0.4（按评审结论调整：流程操作人统一为系统管理员）｜ 状态：待评审

## 一、流程清单（8 个）

| 编号 | 流程名称 | 涉及角色 | 涉及子系统 |
|---|---|---|---|
| FL-INF-01 | 基础信息初始化（Excel 导入） | 系统管理员（唯一角色） | 基础信息 |
| FL-FIN-01 | 缴费与欠费催缴 | 系统管理员（唯一角色） | 财务、基础信息 |
| FL-FIN-02 | 支出记账 | 系统管理员（唯一角色） | 财务、人员、设备 |
| FL-FIN-03 | 月度/季度财务报表 | 系统管理员（唯一角色） | 财务 |
| FL-EMG-01 | 应急响应 | 系统管理员（唯一角色） | 应急、人员、设备、电话簿 |
| FL-ORG-01 | 排班与考勤 | 系统管理员（唯一角色） | 人员 |
| FL-DIS-01 | 纠纷调解 | 系统管理员（唯一角色） | 纠纷、人员、基础信息 |
| FL-EQP-01 | 设备保养与年检 | 系统管理员（唯一角色） | 设备、财务 |

## 二、关键流程活动图

### FL-INF-01 基础信息初始化

```mermaid
flowchart TB
  S["下载 Excel 模板"] --> A["按模板填写楼栋/单元/房产/业主/车位"]
  A --> B["导入系统"]
  B --> C{"逐行校验"}
  C -->|"通过"| D["入库并生成关系"]
  C -->|"失败"| E["生成错误清单"]
  E --> A
  D --> F["人工抽检与补录"]
  F --> G["完成初始化"]
```

### FL-FIN-01 缴费与欠费催缴

```mermaid
flowchart TB
  subgraph 操作环节
    A1["选择收费项目与周期"]
    A2["生成应收账单"]
    A3["核对账单"]
    A4["登记收款"]
  end
  subgraph 系统处理
    B1["按项目×周期×对象生成"]
    B2["账单进入待缴"]
    B3{"全额/部分缴?"}
    B4["更新状态并出收据"]
    B5["欠费台账/到期提醒"]
  end
  subgraph 审核环节
    C1["查看欠费与统计"]
  end
  A1 --> A2 --> B1 --> B2 --> A3 --> A4 --> B3
  B3 -->|"全额"| B4
  B3 -->|"部分"| B4
  B2 --> B5
  B5 --> C1
```

### FL-FIN-02 支出记账

```mermaid
flowchart TB
  A["选择支出分类（工资/维护/水电/外包/杂项）"] --> B["录入金额、日期、说明"]
  B --> C{"需关联对象?"}
  C -->|"工资"| D["引用员工"]
  C -->|"维护"| E["引用设备/维保单位"]
  C -->|"否"| F["直接登记"]
  D --> G["保存支出记录（审计留痕）"]
  E --> G
  F --> G
```

### FL-FIN-03 财务报表

```mermaid
flowchart TB
  A["选择周期（月/季）"] --> B["系统汇总收入流水"]
  B --> C["系统汇总支出流水"]
  C --> D["计算结余与已缴/未缴统计"]
  D --> E["生成报表预览"]
  E --> F["导出 Excel/PDF 或打印"]
```

### FL-EMG-01 应急响应

```mermaid
flowchart TB
  subgraph 发起环节
    A1["选择应急场景"]
    A2["录入时间/地点/情况"]
  end
  subgraph 系统处理
    B1["带出处置步骤"]
    B2["匹配责任人/值班人"]
    B3{"有匹配?"}
  end
  subgraph 指派环节
    C1["人工指派"]
  end
  subgraph 处置环节
    D1["执行处置并记录"]
    D2["结案"]
  end
  subgraph 复盘环节
    E1["复盘（可选）"]
  end
  A1 --> A2 --> B1 --> B2 --> B3
  B3 -->|"是"| D1
  B3 -->|"否"| C1 --> D1
  D1 --> D2 --> E1
```

### FL-ORG-01 排班与考勤

```mermaid
flowchart TB
  A["选择部门/岗位/周期"] --> B["分配员工到班次"]
  B --> C{"冲突检查"}
  C -->|"冲突"| B
  C -->|"无冲突/缺员标记"| D["发布排班表"]
  D --> E["员工签到/签退"]
  E --> F{"与排班对照"}
  F -->|"正常"| G["记入考勤"]
  F -->|"异常"| H["标记异常，管理员审核"]
  H --> G
```

### FL-DIS-01 纠纷调解

```mermaid
flowchart TB
  A["登记纠纷（类型/时间/地点/详情/当事人）"] --> B["指派调解员"]
  B --> C["记录处理方案"]
  C --> D["跟踪处理进度"]
  D --> E{"已解决?"}
  E -->|"否"| C
  E -->|"是"| F["结案归档"]
  F --> G["（可选）补录处理记录"]
```

### FL-EQP-01 设备保养与年检

```mermaid
flowchart TB
  subgraph 系统处理
    A1["按周期/日期生成到期提醒"]
  end
  subgraph 执行环节
    B1["执行保养/年检"]
    B2["登记记录与结果"]
    B3{"结果合格?"}
  end
  subgraph 支出登记环节
    C1["登记维护支出（可选）"]
  end
  A1 --> B1 --> B2 --> B3
  B3 -->|"合格"| D["更新下次提醒日期"]
  B3 -->|"不合格"| E["设备转维修中，关联故障"]
  B2 --> C1
```

## 三、说明

- 所有操作均由系统管理员（唯一角色）执行；流程中的子图仅为环节分组，不代表系统角色；
- 当前流程图以"子图"近似泳道，评审确认环节归属后正式化；
- 异常路径已覆盖：导入失败、部分缴费、应急无人匹配、排班冲突、纠纷未解决、年检不合格；
- 各流程与用例、规则、状态的追溯将在 v0.2 补齐。
