## 二、阅读顺序

1. AM-03 领域概念（认识业务对象）→ AM-02 用例（认识功能边界）→ AM-04 流程（认识业务运转）→ AM-05 状态（认识生命周期）→ AM-06 规则（认识约束）；
2. AM-01 角色权限、AM-07 术语、AM-08 依赖矩阵可随时查阅。

## 三、评审要点

- 用例清单是否覆盖七大模块全部功能，有无遗漏或多余；
- 角色简化（仅系统管理员）后的权限与审计设计是否符合实际使用；
- 概念是否与财务口径、应急场景、设备类型等实际业务一致；
- 流程是否覆盖异常路径（部分缴、超期、故障升级、结案补录）；
- 状态转换是否完整，有无死状态；
- 规则表达是否与现场做法一致。
