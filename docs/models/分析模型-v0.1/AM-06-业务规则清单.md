# AM-6 业务规则清单

> 制品：AM-06 ｜ 版本：v0.4（按评审结论调整：移除岗位授权规则）｜ 状态：待评审
> 编号规则：BR-模块-序号（INF 基础信息 / FIN 财务 / EMG 应急 / ORG 组织 / TEL 电话 / DIS 纠纷 / EQP 设备 / COM 公共）

## 一、基础信息（BR-INF）

| 编号 | 规则描述 | 触发点 | 优先级 |
|---|---|---|---|
| BR-INF-01 | 楼栋-单元-房产层级唯一，房号在单元内不得重复 | 房产保存 | 高 |
| BR-INF-02 | 生成缴费账单前，缴费对象（房产/车位）必须存在有效"房产-业主"关系 | 账单生成 | 高 |
| BR-INF-03 | 固定车位同一时间只能绑定一个房产/业主 | 车位保存 | 高 |
| BR-INF-04 | 业主联系方式、产权关系变更必须留痕（变更记录） | 业主/关系修改 | 高 |
| BR-INF-05 | Excel 导入按模板校验，错误行输出清单，不影响正确行入库 | 导入执行 | 中 |

## 二、财务收费（BR-FIN）

| 编号 | 规则描述 | 触发点 | 优先级 |
|---|---|---|---|
| BR-FIN-01 | 应收账单按"收费项目 × 计费周期 × 缴费对象"生成；同一对象同一周期同一项目不得重复 | 账单生成 | 高 |
| BR-FIN-02 | 缴费金额小于账单金额 → 账单为"部分缴"，剩余计入欠费；大于账单金额 → 阻止并提示 | 收款提交 | 高 |
| BR-FIN-03 | 停车费本期按年缴实现，计费模式枚举预留年/月/临时 | 收费项目维护 | 高 |
| BR-FIN-04 | 支出必须关联支出分类 | 支出保存 | 高 |
| BR-FIN-05 | 工资支出必须引用员工；维护/外包支出可引用设备或维保单位 | 支出保存 | 中 |
| BR-FIN-06 | 退款/减免/调整必须填写原因，且计入审计 | 退款/调整提交 | 高 |
| BR-FIN-07 | 欠费台账口径：未生成/待缴/部分缴/逾期/已缴 | 台账查询 | 高 |
| BR-FIN-08 | 收据编号唯一；打印留痕；支持补打 | 收据打印 | 中 |
| BR-FIN-09 | 月度/季度报表 = 当期收入流水 + 支出流水 + 结余，按分类汇总 | 报表生成 | 高 |
| BR-FIN-10 | 涉及金额的记录删除一律软删除，记录操作人与时间 | 删除操作 | 高 |

## 三、应急处置（BR-EMG）

| 编号 | 规则描述 | 触发点 | 优先级 |
|---|---|---|---|
| BR-EMG-01 | 应急事件必须关联一个应急场景 | 事件发起 | 高 |
| BR-EMG-02 | 处置完成方可结案；复盘可结案后补录 | 结案/复盘 | 高 |
| BR-EMG-03 | 责任人/值班人匹配引用排班与在岗状态；无匹配时需人工指派 | 事件发起 | 高 |
| BR-EMG-04 | 处置记录必须包含时间、操作、结果 | 记录保存 | 高 |
| BR-EMG-05 | 处置步骤版本化，更新不覆盖历史 | 步骤维护 | 中 |
| BR-EMG-06 | 应急事件结案后归档，归档后不得删除，只能补录 | 归档/删除 | 高 |

## 四、人员组织（BR-ORG）

| 编号 | 规则描述 | 触发点 | 优先级 |
|---|---|---|---|
| BR-ORG-01 | 系统仅设系统管理员唯一角色，拥有全部模块权限；敏感操作仍须审计留痕 | 权限配置（预留扩展） | 中 |
| BR-ORG-02 | 离职员工档案保留、账号停用 | 离职办理 | 高 |
| BR-ORG-03 | 同一员工同一时间不能排两个班（冲突阻止或标记） | 排班保存 | 高 |
| BR-ORG-04 | 排班缺员允许发布但必须标记缺口 | 排班发布 | 中 |
| BR-ORG-05 | 考勤异常需管理员审核 | 考勤审核 | 高 |
| BR-ORG-06 | 在岗状态是应急值班匹配的实时数据来源 | 状态更新 | 高 |
| BR-ORG-07 | 部门/岗位支持扩展，层级不限制 | 部门/岗位维护 | 低 |

## 五、便民电话簿（BR-TEL）

| 编号 | 规则描述 | 触发点 | 优先级 |
|---|---|---|---|
| BR-TEL-01 | 电话条目区分"内部员工/外部单位"；员工通讯录同步自人员组织，不手工重复维护 | 条目维护 | 高 |
| BR-TEL-02 | 停用条目保留历史但不展示 | 停用/查询 | 中 |
| BR-TEL-03 | 紧急电话（119/120/110）默认置顶，不允许删除 | 条目维护 | 高 |
| BR-TEL-04 | 号码格式校验（手机/座机） | 条目保存 | 中 |

## 六、民事纠纷调解（BR-DIS）

| 编号 | 规则描述 | 触发点 | 优先级 |
|---|---|---|---|
| BR-DIS-01 | 纠纷状态流：已登记 → 处理中 → 已结案（归档） | 状态变更 | 高 |
| BR-DIS-02 | 结案必须存在至少一条处理方案记录 | 结案 | 高 |
| BR-DIS-03 | 调解员引用员工档案 | 调解员指定 | 高 |
| BR-DIS-04 | 结案后可补录处理记录 | 补录 | 中 |
| BR-DIS-05 | 当事人可引用业主，也可登记外部人员 | 登记 | 中 |

## 七、设备资产台账（BR-EQP）

| 编号 | 规则描述 | 触发点 | 优先级 |
|---|---|---|---|
| BR-EQP-01 | 设备状态：在用/维修中/停用/报废 | 状态变更 | 高 |
| BR-EQP-02 | 保养按设备类型周期提醒；年检按年度提醒 | 到期计算 | 高 |
| BR-EQP-03 | 年检/保养不合格 → 设备转维修中，可关联故障 | 检验登记 | 高 |

| BR-EQP-05 | 设备类型可扩展（电梯/监控/水泵/配电房 +） | 类型维护 | 低 |
| BR-EQP-06 | 维保单位可复用，与设备、支出记录关联 | 关联操作 | 中 |

|---|---|---|---|

| BR-COM-02 | 连续登录失败 5 次锁定账号 | 登录 | 高 |
| BR-COM-03 | 停用账号禁止登录 | 登录 | 高 |

## 九、说明

- 本清单为 v0.2，已按"仅系统管理员角色"评审结论移除岗位授权类规则（原 BR-ORG-01）；
- 每条规则的"来源用例/概念"在 v0.2 逐条补齐；
- 规则冲突时优先级高的生效，评审时请业务人员确认口径。

## 十、评审确认默认参数（来自异常路径核对清单，可调整）

| 编号 | 参数 | 确认默认值 | 说明 |
|---|---|---|---|
| P-01 | 欠费逾期宽限 | 0 天（到期日即逾期），宽限天数可配置 | 口径：超过（到期日 + 宽限）未缴清即逾期 |
| P-02 | 登录失败锁定 | 连续 5 次失败，锁定 30 分钟（可配置） | 单账号场景可管理员重置 |
| P-03 | 事故复盘时限 | 结案后 3 个工作日（可配置） | 逾期在仪表盘提醒 |
| P-04 | 设备保养/年检周期 | 按类型默认（电梯半月保养、年度年检等），单台可覆盖 | 类型默认 + 单台覆盖 |
| P-05 | 收据补打 | 保留原收据号，标注补打次数 | 作废走冲正，不直接删票 |
| P-06 | 收款多缴 | 多缴金额转预存款，抵扣后续账单（简单版：多缴转存 + 自动抵扣 + 余额退还） | 已确认启用，预存款概念已在 M2 设计中落实 |
| P-07 | 应急无人匹配 | 不阻塞发起，发起人默认为第一处置人，事后补指派 | 先处置后补录 |
| P-08 | 纠纷结案类型 | 含"调解成功 / 自行和解 / 转办" | 自行和解也需结案结论 |
| P-09 | 数据备份 | 每日自动备份，保留最近 30 份，建议定期导出外部介质 | 单机场景，3-2-1 原则的本地简化 |
