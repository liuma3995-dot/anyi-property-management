# AM-8 跨子系统依赖矩阵

> 制品：AM-08 ｜ 版本：v0.4（按评审结论调整：移除角色/权限依赖）｜ 状态：待评审

## 一、共享对象与唯一来源

| 共享对象 | 唯一来源（生产方） | 消费方 | 用途 |
|---|---|---|---|
| 业主/房产/车位/房产-业主关系 | 基础信息（INF） | 财务（FIN）、纠纷（DIS） | 缴费对象、当事人 |
| 员工/部门/岗位 | 人员组织（ORG） | 财务（FIN）、应急（EMG）、电话簿（TEL）、纠纷（DIS）、设备（EQP） | 工资、责任/值班、通讯录、调解员、责任人 |
| 排班/在岗状态 | 人员组织（ORG） | 应急（EMG） | 值班匹配 |
| 账号（唯一系统管理员） | 公共（COM） | 全部子系统 | 登录 |
| 审计日志 | 公共（COM） | 全部子系统 | 敏感操作留痕 |
| 基础字典 | 公共（COM） | 全部子系统 | 扩展点（缴费模式、设备类型、场景、支出分类） |
| 设备/维保单位 | 设备（EQP） | 财务（FIN）、应急（EMG） | 维护支出、电梯/配电应急 |
| 紧急电话条目 | 电话簿（TEL） | 应急（EMG） | 处置时一键呼叫 |
| 收费项目/账单 | 财务（FIN） | 公共（COM） | 欠费提醒 |

## 二、关键数据流

| 数据流 | 流向 | 用途 |
|---|---|---|
| 房产/车位 → 应收账单 | INF → FIN | 账单按缴费对象生成 |
| 员工 → 工资支出 | ORG → FIN | 工资核算记账 |
| 设备/维保单位 → 维护支出 | EQP → FIN | 维护费用记账 |
| 排班/在岗 → 应急匹配 | ORG → EMG | 责任人/值班人匹配 |
| 设备（电梯/配电房）→ 应急场景 | EQP → EMG | 场景关联设备信息 |
| 紧急电话 → 应急页面 | TEL → EMG | 一键呼叫 |
| 员工 → 通讯录 | ORG → TEL | 通讯录自动同步 |
| 员工 → 调解员 | ORG → DIS | 指派调解员 |
| 业主 → 纠纷当事人 | INF → DIS | 当事人引用 |
| 账单 → 欠费提醒 | FIN → COM | 仪表盘提醒 |
| 设备 → 保养/年检提醒 | EQP → COM | 仪表盘提醒 |

## 三、依赖规则

1. **唯一来源原则**：业主、房产、车位、员工等基础对象只在本源子系统维护，其他模块只读引用，禁止重复维护；
2. **单向引用**：业务模块引用基础模块（INF/ORG/COM）数据，禁止反向修改；
3. **无循环依赖**：模块间引用方向已固定，新增引用需评审；
4. **弱关联**：故障记录与应急事件、设备与支出之间为可选关联，不强制，避免强耦合；
5. **字典驱动**：缴费模式、设备类型、应急场景、支出分类等扩展点一律走基础字典（COM），不硬编码。
6. **角色简化**：系统仅设系统管理员唯一角色，无角色授权数据流；账号（登录）与业务员工档案解耦。

## 四、与依赖图结论的一致性

本矩阵与计划文档 2.4 的依赖关系图一致：INF 支撑 FIN/DIS，ORG 支撑 FIN/EMG/TEL/DIS，EQP 支撑 FIN/EMG，COM 支撑全部；无第 7 子系统之外的新增依赖。
