## 一、基线范围

本基线冻结以下模型与文档，作为开发实现与测试验收的输入：

- 分析模型 v0.4：AM-01 ~ AM-09 + 异常路径核对清单；
- 设计模型 v0.2：DM-01 ~ DM-08 + 技术选型建议（确认稿）；
- 业务建模计划 v0.2（评审确认基线）；
- 全量追溯矩阵：[追溯矩阵.md](追溯矩阵.md)。

> 版本对齐约定：同一模型集合内所有制品版本与模型集版本一致（分析模型 v0.4：AM-01 ~ AM-09 + 异常路径核对清单；设计模型 v0.2：DM-01 ~ DM-08）；技术选型建议（确认稿）为独立决策文档，版本独立（v1.0）；目录名与任务列表文件名中的 v0.1 为创建时命名，不随版本变更，避免链接失效。

## 五、变更控制规则

基线冻结后，任何变更须走以下流程：

1. 提交变更记录：编号（CHG-xxx）、日期、原因、影响制品；
2. 评估影响：反向追溯矩阵定位受影响用例/概念/库表/界面；
3. 修改对应制品并升版本（v1.x）；
4. 重新评审（按影响范围选择分析/设计/开发评审）；
5. 变更记录归档到本目录 `变更记录/`。
