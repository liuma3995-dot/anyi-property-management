## 九、使用说明

- **正向追溯**：需求条目 → 用例 → 概念/流程/规则/状态 → 设计类 → 库表 → 界面；
- **反向追溯**：从库表或界面定位需求与用例（如修改 t_bill 字段，可反查 RQ-FIN-02/03/07 及对应界面）；
- **变更影响分析**：任何基线变更先在矩阵中定位影响行，再执行 M3 变更控制流程；
- **测试依据**：测试用例可沿本矩阵从需求/用例生成，验收标准与规则（BR）一一对应。
