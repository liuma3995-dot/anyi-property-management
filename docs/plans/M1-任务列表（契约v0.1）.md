## 一、范围与目标

将 60 个用例映射为 API 契约：产出端点映射表、通用规范（鉴权/分页/错误码/时间/枚举）、DTO 与枚举代码，前后端同源引用。契约定稿后按 DZ-2 由项目负责人选定先做 M2（后端）或 M3（前端）。

## 三、契约内容摘要

- 端点分组：auth / baseinfo / org / billing / payments / expenses / reports / emergency / phonebook / disputes / equipment / common（12 组，约 90 个端点）；
- 通用规范：Bearer token 鉴权（/auth/login、/health 除外）；统一信封 `ApiResponse<T>`；`PageRequest/PageResult` 分页；时间 ISO 8601 本地；枚举字符串序列化；软删除；敏感操作审计；导入/导出文件下载端点；
- 错误码：0/40000/40100/40101/40300/40400/40900/42200/50000/50300；
- 关键规则落点：BR-FIN-01/06、BR-INF-02/03、BR-EMG-03、P-06、P-09 等在契约中声明，M2 逐条实现。
