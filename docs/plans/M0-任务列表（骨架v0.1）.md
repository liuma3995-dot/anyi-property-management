## 三、环境核查结论（D0-1）

| 项 | 结论 |
|---|---|
| 本机构建工具链 | 无 Visual Studio / .NET SDK / NuGet.exe；使用 .NET Framework 4.8 自带 MSBuild（4.8.9037）+ 下载的 NuGet.exe 7.9 构建 |
| .NET Framework 4.8 引用程序集 | 未安装 Developer Pack/Targeting Pack；通过 NuGet 包 Microsoft.NETFramework.ReferenceAssemblies.net48 1.0.3 提供（CI 标准做法，无需管理员） |
| 构建方式 | `nuget restore PropertyManagement.sln`（网络）＋ `MSBuild.exe PropertyManagement.sln /p:Configuration=Debug` |
| Win7 SP1 虚拟机 | 本机未见可用 Win7 虚拟机，三环境（Win7/10/11）真机验证延后至 M7（与本机工具链无关） |
| Inno Setup | 本机未安装；M8 打包前安装 |
