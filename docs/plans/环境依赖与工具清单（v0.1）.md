## 三、补装建议

1. **现在**：M1（契约文档 + DTO）与 M2（后端）均可先用命令行构建，**不依赖 VS**；
2. **M2 期间**：视需要装 DB Browser for SQLite（调试数据库）；
3. **M3 开始前**：必须装 VS 2022 Community（到 D 盘），前端 WPF 开发调试绕不开；
4. **M4 收据/报表验证**：用默认虚拟打印机先行；物理打印机待真机部署时由负责人提供；
5. **M8 前**：装 Inno Setup、下载 .NET 4.8 离线安装器。
